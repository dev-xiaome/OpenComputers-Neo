# フロッピーディスク

![何インチ？](oredict:opencomputers:floppy)

フロッピーディスクは、OpenComputers において最も安価で容量の小さい記録メディアです。序盤にデータを保存したり、[コンピューター](../general/computer.md)と[ロボット](../block/robot.md)の間でデータを転送したりするのに便利な手段です。また、ダンジョンのチェストから便利なプログラムが入ったフロッピーディスクが見つかることもあります（OpenPrograms Package Manager など、中央の GitHub リポジトリからプログラムを簡単にインストールできるものが良い例です）。
