# Raid

![40人インスタンス。](oredict:opencomputers:raid)

Raid ブロックは3台の[ハードドライブ](../item/hdd1.md)を収容し、それらを1つの大きなファイルシステムに統合します。この統合されたファイルシステムのサイズは、個々の[ハードドライブ](../item/hdd1.md)の容量の合計となり、Raid に接続されたすべての[コンピューター](../general/computer.md)から利用可能です。

Raid は3台の[ハードドライブ](../item/hdd1.md)がすべて揃っている場合にのみ動作し、ファイルシステムとして表示されます。[ハードドライブ](../item/hdd1.md)のサイズは異なっていても構いません。

注意点として、[ハードドライブ](../item/hdd1.md)を Raid ブロックに追加すると、その内容は消去されます。完成した Raid から1台でも[ハードドライブ](../item/hdd1.md)を取り外すと、Raid 全体のデータが失われます。ディスクを戻しても古いファイルは *復元されません*。Raid は空のファイルシステムとして再初期化されます。

Raid ブロックを破壊してもその内容は保持されるため、データを失うことなく安全に移動させることができます。
