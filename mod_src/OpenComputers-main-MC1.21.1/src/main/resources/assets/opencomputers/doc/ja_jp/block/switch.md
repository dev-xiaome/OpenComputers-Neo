# スイッチ

![架け橋。](oredict:opencomputers:switch)

*このブロックは非推奨であり、将来のバージョンで削除される予定です。* 紛失を避けるために[中継機 (リレイ)](relay.md)にクラフトし直してください。

スイッチを使用すると、コンポーネントを他のネットワークの[コンピューター](../general/computer.md)にさらすことなく、異なるサブネットワーク間でネットワークメッセージを送受信できるようになります。コンポーネントをローカルに保つことは、[コンピューター](../general/computer.md)が誤った[スクリーン](screen1.md)を使用するのを防いだり、コンポーネントのオーバーフロー（[コンピューター](../general/computer.md)がクラッシュして起動しなくなる原因になります）を回避したりするために、通常良い考えです。

このブロックには無線版の[アクセスポイント](accessPoint.md)もあり、メッセージを無線で中継することもできます。無線メッセージは、他の[アクセスポイント](accessPoint.md)や、[無線ネットワークカード](../item/wlanCard1.md)を搭載した[コンピューター](../general/computer.md)によって受信・中継されます。

スイッチと[アクセスポイント](accessPoint.md)は、最近中継したパケットを記憶 *しません*。そのため、ネットワーク内にループを作らないようにしてください。さもないと、同じパケットを複数回受信する可能性があります。スイッチのバッファサイズには限りがあるため、メッセージを頻繁に送信しすぎるとパケットロスが発生します。スイッチと[アクセスポイント](accessPoint.md)をアップグレードして、メッセージの中継速度や内部のメッセージキューサイズを増やすことができます。

パケットの再送信回数には制限があるため、スイッチやアクセスポイントを無制限に連結することはできません。デフォルトでは、パケットは最大5回まで再送信されます。
