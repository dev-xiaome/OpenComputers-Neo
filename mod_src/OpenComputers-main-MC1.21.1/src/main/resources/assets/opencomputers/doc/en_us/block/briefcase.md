# Briefcase

![Portable bureaucracy.](item:opencomputers:briefcase)

The Briefcase provides 18 portable inventory slots.

Right-click it as an item to access its contents. Sneak-use places it in the world, where it can be accessed like a small storage block. Its contents are preserved when it is picked up again.

Unlike the [File Cabinet](filecabinet.md), the Briefcase is general-purpose portable storage and is not limited to document items.
