# ハードディスクドライブ (HDD)

![すぺーす。](oredict:opencomputers:hdd1)

ハードディスクドライブは、OpenComputers における上位ティアの記録メディアです。すべての記録メディアの動作速度は同じですが、上位ティアほど大きな容量を提供します。また、ディスクドライブしか使用できないデバイスもいくつか存在します（サーバーは外部の[ディスクドライブ](../block/diskDrive.md)を利用することも可能ですが）。ハードドライブは [Raid](../block/raid.md) ブロックに配置でき、複数のドライブで同じファイルシステムを共有できます。注意点として、ハードドライブを [Raid](../block/raid.md) に配置すると、ドライブの内容は消去されます。
