# アップグレードコンテナ

![アップグレードを装着できます。](oredict:opencomputers:upgradeContainer1)

アップグレードコンテナは[ロボット](../block/robot.md)用のコンテナ型アップグレードで、完成した[ロボット](../block/robot.md)に通常のアップグレードを装着できるスロットを提供します。そのスロットに保持できるアップグレードの最大ティアは、コンテナのティアと同じです。通常のアップグレードとは異なり、コンテナの「複雑性」はそのティアの2倍になります。複雑性の詳細については[ロボット](../block/robot.md)および[アセンブラ](../block/assembler.md)のドキュメントを参照してください。
