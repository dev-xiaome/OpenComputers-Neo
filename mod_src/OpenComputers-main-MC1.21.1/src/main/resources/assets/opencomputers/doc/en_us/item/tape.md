# Cassette Tape

![Sequential storage for music and data.](oredict:opencomputers:tape)

Cassette tapes are removable sequential byte storage for the [tape drive](../block/tape_drive.md). A tape stores up to 1 MiB of arbitrary bytes. DFPWM audio is only an interpretation of those bytes; the same cassette may store any data a program chooses to write.

Use DFPWM data when you want the tape drive to play the contents as audio. PCM streaming must be enabled by the server for playback to work.
