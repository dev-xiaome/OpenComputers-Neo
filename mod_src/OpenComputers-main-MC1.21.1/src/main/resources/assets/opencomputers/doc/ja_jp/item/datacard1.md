# データカード

![通説に反して、データは保存しません。](oredict:opencomputers:dataCard1)

データカードは、特定のアーキテクチャでは実装が困難であったり、実行が比較的低速であったりするいくつかのアルゴリズムを提供するユーティリティカードです。ハッシュ機能や、基本的な圧縮・展開 (inflate/deflate) 機能を提供します。さらに、インターネットカードと同様に、カードが提供する機能を利用したいくつかのプログラムを含む組み込みファイルシステムも備えています。

一度に処理できるデータサイズには制限があり、各操作には少量のエネルギーを消費することに注意してください。
