# ネットワークカード

![ネットワークへ。](oredict:opencomputers:lanCard)

ネットワークカードにより、[コンピューター](../general/computer.md)はネットワークメッセージを送受信できるようになります。メッセージ（パケット）は、サブネットワーク内のすべての受信ノードにブロードキャストするか、指定したアドレスの特定のノードに送信できます。 [中継機 (リレイ)](../block/relay.md)を使用して、接続されている各サブネットワーク間でメッセージを中継することで、複数のサブネットワークをブリッジできます。ネットワークが1つ以上の[中継機 (リレイ)](../block/relay.md)を介して接続されている場合、受信者が別のサブネットワークにいてもターゲットメッセージを送信可能です。
