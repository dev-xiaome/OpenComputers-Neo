# ホバーブーツ

![踏み出そう。](oredict:opencomputers:hoverBoots)

[ドローン](drone.md)をプログラムするのが面倒なら、別の使い道があります：踏み台です！ あるいは、高性能なインラインスケートのようなものです。そんな感じの何かです。

いずれにせよ、このブーツにはいくつかの便利な特性があります。電力がある限り、より高くジャンプできるようになり、非常に高い場所から着地した際の衝撃を吸収してくれます。具体的には、最大4ブロックの高さまでジャンプでき、着地衝撃を3分の1に抑えます。

さらに、常に浮遊状態にあるため、最大1ブロックの高さの段差をスムーズに上ることができます。これは、山を駆け上がるときなどに非常に便利です。Minecrafter の間ではごく一般的なフィットネス習慣だそうですね。と、耳にしました。

このブーツは、OpenComputers の[充電器](../block/charger.md)や、Applied Energistics 2 の充電器、IndustrialCraft 2 のバッテリボックス、Thermal Expansion の Energetic Infuser などのデバイスで充電できます。

任意の染料と一緒にクラフトすることで、ブーツの色を変更できます。革の防具と同様に、複数の染料を同時または連続して適用することで、非常に多様な色を作成可能です。色は、水入りバケツと一緒にクラフトするか、大釜に投げ込むことで取り除くことができます。
