# ナビゲーションアップグレード

![迷子です。またです。](oredict:opencomputers:navigationUpgrade)

ナビゲーションアップグレードは、インストールされたデバイスに位置と方位の情報を提供します。アップグレードが提供する座標は、アップグレードのクラフトに使用された地図の中心からの相対位置であり、動作範囲はその地図のサイズに依存します。

ナビゲーションアップグレード内の地図は、新しい地図と一緒に再クラフトすることで変更可能です。古い地図はプレイヤーに返却されます。

なお、このアップグレードは1つ以上の[ウェイポイント](../block/waypoint.md)と組み合わせて使用することで、はるかに便利になります。
