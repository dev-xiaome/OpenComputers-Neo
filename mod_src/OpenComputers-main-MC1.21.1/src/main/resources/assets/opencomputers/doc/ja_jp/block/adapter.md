# アダプター

![100%増量中。](oredict:opencomputers:adapter)

アダプターを使用すると、[コンピューター](../general/computer.md)はバニラのブロックや他のMODのブロックとやり取りできるようになります。アダプターに隣接するサポート対象のブロックは、アダプターに接続された[コンピューター](../general/computer.md)にコンポーネントとして表示されます。

これに加えて、アダプターには特定のアップグレードを搭載するためのスロットが用意されています。例えば、[インベントリコントローラーアップグレード](../item/inventoryControllerUpgrade.md) を使用すると、アダプターの隣にあるインベントリからより詳細な情報を取得できるようになります。これは、アップグレードをデバイス（[ロボット](robot.md)や[ドローン](../item/drone.md)など）に取り付けた場合と同様の機能です。また、[タンクコントローラーアップグレード](../item/tankControllerUpgrade.md) は、アダプターの隣にある液体タンクに対して同様の機能を提供します。
さらに、バインド済みの [MFU](../item/mfu.md) を挿入することで、少し離れた場所にあるブロックともやり取りできます。
