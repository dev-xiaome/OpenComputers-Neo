# アクセスポイント

![AAA](oredict:opencomputers:accessPoint)

*このブロックは非推奨であり、将来のバージョンで削除される予定です。* 紛失を避けるために[中継機](relay.md)にクラフトし直してください。

アクセスポイントは、[スイッチ](switch.md)の無線版です。サブネットワークを分離して、その中のマシンが他のネットワークの[コンポーネント](../general/computer.md)を見えないようにしつつ、他のネットワークのマシンへのネットワークメッセージの送信を許可するために使用できます。

これに加えて、このブロックはリピーターとして機能し、有線メッセージを有線メッセージとして他のデバイスへ、あるいは無線メッセージを有線または無線メッセージとして再送信することもできます。

[スイッチ](switch.md)とアクセスポイントは、最近中継したパケットを記憶*しません*。そのため、ネットワーク内にループを作らないようにしてください。さもないと、同じパケットを複数回受信する可能性があります。スイッチのバッファサイズには限りがあるため、ネットワークメッセージを頻繁に送信しすぎるとパケットロスが発生する可能性があります。スイッチとアクセスポイントをアップグレードして、メッセージの中継速度や内部のメッセージキューサイズを増やすことができます。

パケットの再送信回数には制限があるため、[スイッチ](switch.md)やアクセスポイントを無制限に連結することはできません。デフォルトでは、パケットは最大5回まで再送信されます。
