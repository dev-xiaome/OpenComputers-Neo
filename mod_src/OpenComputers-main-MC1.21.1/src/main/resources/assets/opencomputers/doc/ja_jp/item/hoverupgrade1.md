# ホバーアップグレード

![羽のように浮かぶ。](oredict:opencomputers:hoverUpgrade1)

ホバーアップグレードにより、[ロボット](../block/robot.md)は通常よりはるかに高い位置を飛行できるようになります。[ドローン](drone.md)とは異なり、ロボットはデフォルトで飛行高度が 8 ブロックに制限されています。壁を上ったり沿ったりして移動できるため、通常これは大きな問題にはなりませんが、一般的な移動ルールは以下の通りです：
- ロボットは、開始地点または目標地点のいずれかが有効な場合にのみ移動できます（例：橋の建設を可能にするため）。
- ロボットの真下の位置は常に有効です（常に下降できます）。
- 固形ブロックから `flightHeight`（飛行高度）までの高さにある位置は有効です（制限付きの飛行能力）。
- その位置に向かって固形な面を持つ隣接ブロックがある位置は有効です（ロボットは「登る」ことができます）。

これらのルール（わかりやすくするためにルール 2「常に下降できる」を除外）は、次のように視覚化できます：
![ロボットの移動ルールの視覚化。](opencomputers:doc/img/robotMovement.png)

飛行高度の制限を気にしたくないのであれば、このアップグレードこそが求めるものです。
