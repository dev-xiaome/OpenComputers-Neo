# テクスチャピッカー (Texture Picker)

![単なるリスキンだなんて、どういう意味ですか？](oredict:opencomputers:texturePicker)

テクスチャピッカーは、[3Dプリンター](../block/printer.md)のモデルを作成する際に非常に便利です。世界にあるブロックをこのツールで（スニーク）アクチュベートするだけで、そのブロックに使用されているテクスチャ名を取得できます。 免責事項：チェストのような特殊な描画を行うブロックでは正しく動作しない場合があります。

テクスチャ名を素早く調べるのに便利ですが、このツールで取得できるテクスチャ以外も使用可能であることを覚えておいてください。テクスチャ名（それが *ブロック* のテクスチャであること）さえわかれば、それを[3Dプリント](../block/print.md)で使用することができます。
