# コンポーネントバス (Component Bus)

![もっと……もっとだ！](oredict:opencomputers:componentBus1)

コンポーネントバスは[サーバー](server1.md)専用のアップグレードで、サーバーがシャットダウンすることなく、同時により多くのコンポーネントと通信できるようにします。[CPU](cpu1.md) と同様に、上位ティアのバスほど接続可能なコンポーネント数の上限が高くなります。また、上位ティアの[サーバー](server1.md)はより多くのコンポーネントバスを搭載でき、非常に多くのコンポーネントと通信できるようになります。

各コンポーネントバスによって拡張されるコンポーネント接続数は以下の通りです：
- ティア 1: 8 コンポーネント
- ティア 2: 12 コンポーネント
- ティア 3: 16 コンポーネント
