# アセンブラ

![より強く、より速く、より良く。](oredict:opencomputers:assembler)

アセンブラは、[ロボット](robot.md)、[ドローン](../item/drone.md)、[タブレット](../item/tablet.md)などのより複雑な電子デバイスを構築するために使用される高度なワークステーションです。デバイスの組み立てには大量のエネルギーを必要とするため、[コンデンサ](capacitor.md)で十分な電力を供給することをお勧めします。

アセンブラを使用してデバイスを構築するには、そのデバイスのベースパーツを挿入します。[ロボット](robot.md)の場合は任意のティアの[コンピューターケース](case1.md)、[タブレット](../item/tablet.md)の場合は[タブレットケース](../item/tabletCase1.md)です。すべての OpenComputers のインベントリと同様に、パーツは特定のスロットに挿入できます。スロットの上にカーソルを置くと、インベントリ内の挿入可能なパーツが強調表示されます。NEI を開いて OpenComputers のアイテムを表示するようにフィルタリングしている場合、互換性のあるアイテムは NEI 上でも強調表示されます。デバイスに含めたいパーツを順次挿入してください。特に、オペレーティングシステムを含めるか、後でインストールする方法を確保するように注意してください（例えば、ロボットの場合は後で[フロッピー](../item/floppy.md)を抜き差しできるように[ディスクドライブ](diskDrive.md)をインストールできます）。ほとんどのデバイスでは、後で別の [EEPROM](../item/eeprom.md) と一緒にクラフトすることで、内蔵された [EEPROM](../item/eeprom.md) を交換できます。デバイス内の既存の [EEPROM](../item/eeprom.md) はインベントリに返却されます。

また、[ロボット](robot.md)に[スクリーン](screen1.md)を持たせるには[スクリーン (ティア 1)](screen1.md)をインストールする必要があり、スクリーン上でタイピングを可能にするには[キーボード](keyboard.md)をインストールする必要があります。[タブレット](../item/tablet.md)の場合、[スクリーン](screen1.md)は[タブレットケース](../item/tabletCase1.md)にプリインストールされていますが、タイピングを行いたい場合は[キーボード](keyboard.md)をインストールする必要があります。

すべてが整ったら、スタートボタンを押して、デバイスが組み立てられ充電されるのを待ちます。組み立て後のデバイスは構成を *変更できない* ことに注意してください。何かを忘れたり間違いをしたりした場合は、[分解機](disassembler.md)を使用してデバイスを分解する必要があります。

複雑性についての最終的な注意点：アイテムのティアによって必要な複雑性が決まります。ティア 1 アイテムは複雑性 1、ティア 2 は 2、ティア 3 は 3 を必要とします。コンテナアップグレードは例外で、複雑性はコンテナのティアの 2 倍になります（例：ティア 2 の[アップグレードコンテナ](../item/upgradeContainer1.md)は複雑性 4 を必要とし、[カードコンテナ](../item/cardContainer1.md)も同様です）。
