# マイクロコントローラー (マイコン)

![侮るなかれ。](block:OpenComputers:microcontroller)

マイクロコントローラーは、[アセンブラ](assembler.md)で[マイクロコントローラーケース](../item/microcontrollerCase1.md)を使用して構築されます。[コンピューター](../general/computer.md)と比較して機能は少ないですが、安価に構築できます。特に、外部のコンポーネントとやり取りすることは*できません*。

マイクロコントローラーには、[CPU](../item/cpu1.md)、[メモリ (RAM)](../item/ram1.md)、拡張カードなどの様々なコンポーネントを搭載できます。[ハードディスクドライブ](../item/hdd1.md)を搭載することはできませんが、[EEPROM](../item/eeprom.md) スロットを備えており、特定のタスク用にプログラムして使用できます。[コンピューターケース](case1.md)に対する利点として、[ピストンアップグレード](../item/pistonUpgrade.md)などの一部のアップグレードも利用可能です。
