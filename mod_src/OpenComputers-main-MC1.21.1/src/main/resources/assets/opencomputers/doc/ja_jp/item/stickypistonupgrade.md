# 粘着ピストンアップグレード

![押せ。引け。](oredict:opencomputers:stickyPistonUpgrade)

粘着ピストンアップグレードは、[ピストンアップグレード](pistonupgrade.md)の強化版で、一部のデバイスをバニラの粘着ピストンのように動作させることができます。インストールすると、ピストンコンポーネントが利用可能になります。メソッドは `push()` と `pull()` です。これらが呼び出されると、デバイスはバニラの粘着ピストンのように動作し、正面方向にあるブロックを押し出したり引き寄せたりしようと試みます。 [ロボット](../block/robot.md)と[マイクロコントローラー](../block/microcontroller.md)の場合は正面を指し、[タブレット](tablet.md)の場合はプレイヤーの向いている方向を使用します。
