# リモートターミナル (Remote Terminal)

![リモートアクセス。](oredict:opencomputers:terminal)

リモートターミナルは、[ターミナルサーバー](terminalserver.md)を介してコンピューターを遠隔操作するために使用されます。使用するには、[ラック](../block/rack.md)に設置された[ターミナルサーバー](terminalserver.md)をアクチュベートしてください（世界にある[ラック](../block/rack.md)ブロックをクリックし、対象の[ターミナルサーバー](terminalserver.md)を指定してターミナルをバインドします）。

[ターミナルサーバー](terminalserver.md)は、ターミナル経由で制御可能な仮想的な[スクリーン](../block/screen1.md)と[キーボード](../block/keyboard.md)を提供します。 [ターミナルサーバー](terminalserver.md)と同じサブネットワークに別の実体のスクリーンやキーボードが接続されている場合、予期しない動作を引き起こす可能性があるため、通常は避けるべきです。バインドした後のターミナルを手に持って使用すると、[スクリーン](../block/screen1.md)に取り付けられた[キーボード](../block/keyboard.md)と同様の GUI が開きます。

1つの[ターミナルサーバー](terminalserver.md)に対して複数のターミナルをバインドできますが、それらは仮想的な[スクリーン](../block/screen1.md)と[キーボード](../block/keyboard.md)を共有するため、すべて同じ情報を表示します。1つの[ターミナルサーバー](terminalserver.md)にバインドできるターミナルの数には制限があります。バインド数が上限に達している状態で新しくバインドすると、最初にバインドされたターミナルのバインドが解除されます。
