# Solid State Drive

![No moving parts.](oredict:opencomputers:ssd1)

Solid state drives are silent, high-capacity alternatives to [hard disk drives](hdd1.md). They fit into the same component slots, but read and write files faster while using less power.

Like other storage media, an SSD can be configured by holding it and right-clicking. Managed mode provides a normal filesystem. Unmanaged mode exposes raw sectors through the `drive` component; SSDs do not incur mechanical seek delays in either mode.

An SSD can be erased by crafting it by itself. This permanently removes its files, label, lock, and low-level drive contents.
