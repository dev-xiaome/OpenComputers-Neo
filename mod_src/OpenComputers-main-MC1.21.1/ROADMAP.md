# Roadmap

This is the working list for the Minecraft 1.21.1 port. It intentionally tracks
project-level gaps; implementation notes belong in issues and pull requests.

## Compatibility

- [ ] Restore Applied Energistics 2 integration.
- [ ] Restore TIS-3D integration when a compatible release is available.
- [ ] Complete JEI integration against the current API.

## Gameplay and content

- [ ] Port advancements.
- [ ] Add tier-four parts.
- [x] Finish solid-state drive support.
- [ ] Add an `/opencomputers` (or `/oc`) command for safe config reloads and
      administration.

## Longer-term ideas

- [ ] Investigate an advanced EEPROM or custom WebAssembly runtime.

Items here are plans, not release promises. Please open an issue before
starting a large feature so implementation and compatibility expectations can
be agreed on first.
