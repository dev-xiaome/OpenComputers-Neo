# ドローン

![監視されています。](item:opencomputers:drone)

ドローンは、[アセンブラ](../block/assembler.md)で [ドローンケース](droneCase1.md) を使用して構築されます。実体（エンティティ）ベースの[ロボット](../block/robot.md)であり、より安価で機能が制限されています。移動方法が異なり、[ロボット](../block/robot.md)よりもはるかに高速に動くことができ、通常は[コンピューター](../general/computer.md)上のプログラムによって制御されます。ドローンが実行すべきコマンドを待機したり、自律的に動作したりするには、構成済みの [EEPROM](eeprom.md) が必要です。
