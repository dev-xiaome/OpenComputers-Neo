# 発電機アップグレード (Generator Upgrade)

![ジェネレーター X。](oredict:opencomputers:generatorUpgrade)

発電機アップグレードを使用すると、デバイスが移動中に燃料を補給できるようになります。現在は石炭などの固形燃料のみに対応しています。1スタックの燃料を保持できる内部インベントリを備えています。余剰の燃料は、対応するコンポーネント API メソッドを使用して発電機から取り出すことができます。[ロボット](../block/robot.md)から発電機アップグレードを取り外すと、その中身は世界にドロップされます。

発電機の効率は他の MOD の一般的な発電機よりも低いため、通常は[充電器](../block/charger.md)を使用してデバイスに電力を供給するほうが燃料効率が良くなります。
