# ロボット

![彼の名はトボール (Tobor)。](block:OpenComputers:robot)

[コンピューター](../general/computer.md)とは異なり、ロボットはプレイヤーと同じように移動したり、世界とやり取りしたりすることができます。ただし、ロボットは外部のコンポーネントと直接やり取りすることは*できません*！ [コンピューター](../general/computer.md)や他のロボットと通信する必要がある場合は、[無線ネットワークカード](../item/wlanCard1.md)を使用するか、[レッドストーンカード](../item/redstoneCard1.md)などを介したレッドストーン信号による低レベルプロトコルを作成してください。

ロボットは、[アセンブラ](assembler.md)に任意のティアの[コンピューターケース](case1.md)を配置することで構築されます。上位ティアの[コンピューターケース](case1.md)を使用すると、より上位の [CPU](../item/cpu1.md) を搭載できるため、より複雑なロボットを構築できます。ロボットの「複雑性」（[アセンブラ](assembler.md)に表示されます）は、ロボットスロットに配置されるコンポーネントやアップグレードのティアによって決まります。上位ティアのコンポーネントは、下位ティアのものよりも複雑性を大きく増加させます。ロボットの複雑性が高すぎる場合、[アセンブラ](assembler.md)はロボットを構築できません。

ロボットの機能を拡張するために、様々なアップグレードを搭載できます。これには、[インベントリ](../item/inventoryUpgrade.md)および[インベントリコントローラー](../item/inventoryControllerUpgrade.md)アップグレード、[タンクアップグレード](../item/tankUpgrade.md)、[ナビゲーションアップグレード](../item/navigationUpgrade.md)などが含まれます。[アップグレードコンテナ](../item/upgradeContainer1.md)や[カードコンテナ](../item/cardContainer1.md)をロボットに搭載することで、アップグレードやコンポーネントをその場で着脱できるようになります。また、ロボット内部に[ディスクドライブ](diskDrive.md)を配置して[フロッピーディスク](../item/floppy.md)を挿入できるようにすることもでき、これによりロボットに [OpenOS](../general/openOS.md) をインストールできます（別の方法として、[コンピューター](../general/computer.md)を使用して空の[ハードドライブ](../item/hdd1.md)に [OpenOS](../general/openOS.md) をインストールし、インストール済みの[ハードドライブ](../item/hdd1.md)を構成要素としてロボットのアセンブリに使用することも可能です）。
