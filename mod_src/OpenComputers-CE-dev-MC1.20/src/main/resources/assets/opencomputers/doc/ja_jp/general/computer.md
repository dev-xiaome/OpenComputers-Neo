# コンピューター

コンピューターは、様々な種類の[ブロック](../block/index.md)やコンポーネントを使用して構築されます。コンピューターを構築するために最低限必要なのは、[ケース](../block/case1.md)、[スクリーン](../block/screen1.md)、そして[キーボード](../block/keyboard.md)です。[ケース](../block/case1.md)と[スクリーン](../block/screen1.md)には異なるティアがあり、異なる機能を提供したり、より複雑なコンピューターシステムの構築を可能にしたりします。 [スクリーン](../block/screen1.md)を操作できるようにするには、[キーボード](../block/keyboard.md)を[スクリーン](../block/screen1.md)に隣接させて（側面または前面に直接）配置する必要があります。

基本構造が完成したら、[ケース](../block/case1.md)の中にコンポーネントを配置できます。これらのコンポーネントには、[CPU](../item/cpu1.md)、[メモリ (RAM)](../item/ram1.md)、[ハードドライブ (HDD)](../item/hdd1.md)、[グラフィックスカード](../item/graphicsCard1.md)（スクリーンを使用するために必要）、[ネットワークカード](../item/lanCard.md)（コンピューターネットワーク間の通信用）などが含まれます。多くのコンポーネントが用意されており、特定の目的に合わせた高度に柔軟なシステムを構成できます。

下位ティアのコンピューターでは、[フロッピー](../item/floppy.md)ディスクを読み取るための[ディスクドライブ](../block/diskDrive.md)も必要です。コンピューターを最初に起動するには [OpenOS](openOS.md) [フロッピー](../item/floppy.md) ディスクが必要で、これを使用して [HDD](../item/hdd1.md) にオペレーティングシステムをインストールします。[HDD](../item/hdd1.md) にインストールした後は、[フロッピー](../item/floppy.md) ディスクは不要になります。追加のソフトウェアも [フロッピー](../item/floppy.md) ディスクとして入手可能で（Open Programs Package Manager (OPPM) など）、ダンジョンの戦利品などから入手できます。

最後のステップは、コンピューターに電源を供給することです。OpenComputersは主要な電力MODと互換性があり、多くのブロックに直接給電できます。外部電源に接続できるブロックは、ツールチップにブロックの電力変換速度に関するエントリが含まれているかどうかで確認できます。
複数のコンピューターを持つ大規模なネットワークでは、[パワーコンバーター](../block/powerConverter.md)（他MODの電力をOC内部の電力タイプに変換）、[パワーディストリビューター](../block/powerDistributor.md)（ネットワーク上の各コンピューターに電力を分配）、および[コンデンサ](../block/capacitor.md)（ネットワーク用の蓄電器）を使用して、[ケーブル](../block/cable.md)で各コンピューターを接続できます。
