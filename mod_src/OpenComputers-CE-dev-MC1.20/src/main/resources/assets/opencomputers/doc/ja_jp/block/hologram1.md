# ホログラム投影機

![これは現実？ それとも幻想？](oredict:opencomputers:hologram1)

ホログラム投影機は体積表示（ボクセル表示）ディスプレイです。つまり、接続された[コンピューター](../general/computer.md)によって個別にオン・オフを切り替え可能なボクセルの3次元配列を提供します。第2ティアの投影機は、第1ティアと同じ解像度ですが、各ボクセルをユーザーが定義可能な3つの異なる色で表示できます。

ホログラムの上面または底面を[レンチ](../item/wrench.md)で叩くことで、垂直軸に沿って回転させることができます。これにより、ソフトウェア側で出力を変換する手間を省けます。また、ホログラムは必要に応じて拡大・縮小することも可能です。
