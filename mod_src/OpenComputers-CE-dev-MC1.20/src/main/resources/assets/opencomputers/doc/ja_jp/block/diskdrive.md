# ディスクドライブ

![回り回って……](oredict:opencomputers:diskDrive)

ディスクドライブは、接続された[コンピューター](../general/computer.md)を使用して[フロッピーディスク](../item/floppy.md)を読み取るために使用されます。下位ティアの[コンピューターケース](case1.md)にはフロッピースロットが内蔵されていないため、[コンピューター](../general/computer.md)を起動するためのオペレーティングシステムを用意する際に役立ちます。 [OpenOS](../general/openOS.md) ディスクは、空の[フロッピーディスク](../item/floppy.md)と[マニュアル](../item/manual.md)をクラフトすることで作成できます。

また、[ロボット](robot.md)にインストールして、[ロボット](robot.md)に[フロッピーディスク](../item/floppy.md)を挿入できるようにすることもできます。ロボットとの間でデータを転送する他の方法はネットワーク（[ネットワークカード](../item/lanCard.md)など）しかないため、これは非常に便利です。

[フロッピー](../item/floppy.md)を手に持った状態でスニーク右クリック（シフト右クリック）することで、ディスクドライブの GUI を開かずに[ディスク](../item/floppy.md)を出し入れできます。
