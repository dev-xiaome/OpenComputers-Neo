# トラクタービーム (Tractor Beam)

![転送してください。](oredict:opencomputers:tractorBeamUpgrade)

トラクタービームアップグレードにより、デバイスは周囲3ブロック以内のアイテムを拾い上げることができるようになります。これは、木こりや他の農場で[ロボット](../block/robot.md)を使用する場合や、周囲の複数のブロックを同時に破壊するツール（Tinker's Construct のツールなど）をロボットに使用させる場合に非常に有効です。各操作で、範囲内のアイテムスタック1つを吸い込もうと試み、エネルギーを消費します。
