# 3Dプリント

![思いのままに。](block:OpenComputers:print)

3Dプリントは[3Dプリンター](printer.md)を使用して作成されます。主に装飾目的を意図していますが、レッドストーン信号に反応したり放出したりするように作成することもでき、少しだけ機能性を持たせることも可能です。

3Dプリントは[3Dプリンター](printer.md)の入力スロットに入れることでリサイクルできます。これにより、印刷に使用された[カメリウム](../item/chamelium.md)の一部を再利用できます。印刷時に使用されたインク（色）はリサイクルされません。

OpenComputers の詳細ツールチップ表示キー（デフォルトは `Shift`）を押し続けると、プリントの動作状態（ある場合）が表示されます。

プリントされたブロックは Forge MultiPart と互換性があります。導入されている場合、衝突しない限り、複数のプリントを1つのブロック空間に配置できます（1つのモデルの形状制限を超えない範囲で）。Forge MultiPart の性質上、松明、レバー、ケーブル、あるいは Project Red のレッドアロイワイヤーなど、他の Forge MultiPart 互換ブロックと同じブロック空間にプリントを配置することも可能です。
