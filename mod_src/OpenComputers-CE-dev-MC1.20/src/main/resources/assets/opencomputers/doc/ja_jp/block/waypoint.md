# ウェイポイント

![「こっちだ！」「いや、あっちだ！」](oredict:opencomputers:waypoint)

ウェイポイントの使用価値はそれ自体ではなく、どのように使われるかにあります。[ナビゲーションアップグレード](../item/navigationUpgrade.md)はウェイポイントを検出できるため、ナビゲーションアップグレードを搭載したデバイスはこれらのウェイポイントを使用して世界をナビゲートできます。これは、[ロボット](robot.md)や[ドローン](../item/drone.md)などのデバイス向けに、簡単に再利用可能なプログラムを作成する際に特に便利です。

なお、ナビゲーションアップグレードで取得される実際の位置は、*ウェイポイントの正面にあるブロック*（パーティクル効果で示されます）です。これにより、チェストの隣かつ上などにウェイポイントを配置し、プログラム内でウェイポイントの回転を考慮することなく、その位置を「チェストの上」として参照できます。

ウェイポイントには、ナビゲーションアップグレードで問い合わせたときに使用できる2つのプロパティがあります：現在受信しているレッドストーン信号のレベルと、編集可能なラベルです。ラベルは32文字の文字列で、GUI またはウェイポイントブロックが公開しているコンポーネントを介して編集できます。これら2つのプロパティを使用して、デバイス上でウェイポイントをどう扱うかを決定できます。例えば、仕分けプログラムにおいて、高いレッドストーン信号を持つすべてのブロックを入力とし、低い信号を持つブロックを出力として扱うように設定できます。
