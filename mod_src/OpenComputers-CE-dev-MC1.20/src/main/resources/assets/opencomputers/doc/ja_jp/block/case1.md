# コンピューターケース

![念のため (Just in case)。](oredict:opencomputers:case1)

コンピューターケースには3つのティアがあり、それによって挿入可能なコンポーネントが制限されます。さらに、クリエイティブモード専用のティアも存在します。コンピューターケースを[アセンブラ](assembler.md)に入れて[ロボット](robot.md)を構築することも可能です。

スロットに挿入可能なコンポーネントの最大ティアは、ティア制限のあるスロットの隅にある小さなローマ数字で確認できます。例えば、ティア 2 スロットにはティア 1 コンポーネントを挿入できます。

ティア 1 ケースには、以下のコンポーネントを搭載可能です：
- 2x ティア 1 拡張カード（[グラフィックスカード](../item/graphicsCard1.md)、[ネットワークカード](../item/lanCard.md)など）
- 1x ティア 1 [CPU](../item/cpu1.md)
- 2x ティア 1 [RAM](../item/ram1.md)
- 1x ティア 1 [HDD](../item/hdd1.md)

ティア 2 ケースには、以下のコンポーネントを搭載可能です：
- 1x ティア 1 拡張カード（[グラフィックスカード](../item/graphicsCard1.md)、[ネットワークカード](../item/lanCard.md)など）
- 1x ティア 2 拡張カード
- 1x ティア 2 [CPU](../item/cpu2.md)
- 2x ティア 2 [RAM](../item/ram3.md)
- 1x ティア 1 [HDD](../item/hdd1.md)
- 1x ティア 2 [HDD](../item/hdd2.md)

ティア 3 ケースには、以下のコンポーネントを搭載可能です：
- 1x ティア 3 拡張カード（[グラフィックスカード](../item/graphicsCard1.md)、[ネットワークカード](../item/lanCard.md)など）
- 2x ティア 2 拡張カード
- 1x ティア 3 [CPU](../item/cpu3.md)
- 2x ティア 3 [RAM](../item/ram5.md)
- 1x ティア 2 [HDD](../item/hdd2.md)
- 1x ティア 3 [HDD](../item/hdd3.md)
- 1x [フロッピーディスク](../item/floppy.md)

ティア 4 (クリエイティブ) ケースには、以下のコンポーネントを搭載可能です：
- 3x ティア 3 拡張カード（[グラフィックスカード](../item/graphicsCard1.md)、[ネットワークカード](../item/lanCard.md)など）
- 1x ティア 3 [CPU](../item/cpu3.md)
- 2x ティア 3 [RAM](../item/ram5.md)
- 2x ティア 3 [HDD](../item/hdd3.md)
- 1x [フロッピーディスク](../item/floppy.md)
