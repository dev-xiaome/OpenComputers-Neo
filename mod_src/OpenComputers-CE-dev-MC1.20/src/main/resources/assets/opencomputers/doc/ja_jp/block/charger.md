# 充電器

![よし、やろう。](oredict:opencomputers:charger)

充電器は、[ロボット](robot.md)、[ドローン](../item/drone.md)、[タブレット](../item/tablet.md)などのデバイスを充電するために使用されます。充電器を動作させるには、レッドストーン信号を入力する必要があります。充電速度は入力されたレッドストーン信号の強度に基づき、信号強度 15 で 100% の充電速度になります。

なお、このロジックは充電器を[レンチ](../item/wrench.md)で叩くことで反転させることができます。反転モードでは、デフォルトで 100% の充電速度となり、レッドストーン信号の強度が上がるにつれて充電速度が低下します。

[タブレット](../item/tablet.md)を充電器に配置すると、最初の[ハードドライブ](../item/hdd1.md)が充電器に接続された[コンピューター](../general/computer.md)からも見えるようになります。これは[ディスクドライブ](diskDrive.md)内の[フロッピー](../item/floppy.md)と同様の仕組みです。これにより、[コンピューター](../general/computer.md)と[タブレット](../item/tablet.md)の間でデータを転送できます。
