# 抽象バスカード (Abstract Bus Card)

![さらなるネットワーク！](oredict:opencomputers:abstractBusCard)

このカードを使用すると、[コンピューター](../general/computer.md)、[サーバー](server1.md)、および[ロボット](../block/robot.md)が StargateTech2 の抽象バス (Abstract Bus) とやり取りできるようになります。カードをインストールすると、これらのブロックが抽象バスに接続され、抽象バスを介してメッセージを送信するためのコンポーネントが利用可能になります。受信した抽象バスのメッセージは、マシン内に注入される信号に変換されます。
