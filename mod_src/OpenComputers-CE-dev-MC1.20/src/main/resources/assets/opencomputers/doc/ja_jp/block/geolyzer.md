# ジオライザー (地質調査機)

![いい岩だ。](oredict:opencomputers:geolyzer)

ジオライザーを使用すると、周囲の地形をスキャンしてブロックのおおよその硬さを調べることができます。この情報は、[ホログラム投影機](hologram1.md)にエリアのマップを表示したり、価値のあるブロック（鉱石は通常、土や石よりも硬いです）を特定したりするのに役立ちます。ジオライザーのスキャン結果には一定のノイズが含まれますが、理論上は複数回のスキャンを行うことで、ブロックの硬さをより正確に判断できます。

ジオライザーは、[ロボット](robot.md)や[タブレット](../item/tablet.md)にアップグレードとしてインストールすることもでき、周囲をスキャンできるようになります。ただし、スキャンの実行にはエネルギーを消費するため、過度な使用はデバイスのバッテリーを消耗させます。
