# 無線ネットワークカード (WLAN Card)

![癌になるかもしれません。ならないかもしれません。](oredict:opencomputers:wlanCard2)

無線ネットワークカードは、無線ネットワークメッセージを送受信できるように[ネットワークカード](lanCard.md)をアップグレードしたものです。ティア 2 のカードは有線メッセージの送受信も可能です。信号強度は、送信したメッセージが届く距離に直結し、その強度はブロック単位の距離に等しくなります。

信号強度が高いほど、メッセージ1つの送信により多くのエネルギーを消費します。送信者と受信者の間の地形も、メッセージが正常に送信されるかどうかを決定します。ブロックを貫通するには、信号強度からブロックの硬さが減算されます（空気ブロックの場合は最低でも 1 減ります）。受信者に到達するだけの強度が残っていない場合、メッセージは受信されません。ただし、これは厳密な数値計算ではありません。時にはメッセージが届くこともあります。一般的には、送信者と受信者の間の見通しをクリアに保つことが推奨されます。
