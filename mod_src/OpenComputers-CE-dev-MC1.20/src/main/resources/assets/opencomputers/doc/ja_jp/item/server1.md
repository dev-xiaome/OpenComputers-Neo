# サーバー

![正しい奉仕を。](oredict:opencomputers:server1)

サーバーは上位ティアの[コンピューター](../general/computer.md)の一種です。手に持って使用することで（バックパックやエンダーポーチを開くように）、サーバーの構成が可能です。また、[ラック](../block/rack.md)に設置した後は、サーバーをアクチュベート（ラックの前面にある対応する位置を狙う）することで構成できます。サーバーを動作させるには、[ラック](../block/rack.md)の中に配置する必要があります。詳細については、[ラック](../block/rack.md)のエントリを参照してください。

ティア 1 サーバーは、以下のコンポーネントを搭載可能です：
- 1x ティア 2 [CPU](cpu2.md)
- 2x ティア 2 [RAM](ram3.md)
- 2x ティア 2 [HDD](hdd2.md)
- 1x ティア 2 [コンポーネントバス](componentBus2.md)
- 2x 拡張カード (ティア 2)
- 1x [EEPROM](eeprom.md)

ティア 2 サーバーは、以下のコンポーネントを搭載可能です：
- 1x ティア 3 [CPU](cpu3.md)
- 3x ティア 3 [RAM](ram5.md)
- 3x ティア 3 [HDD](hdd3.md)
- 2x ティア 3 [コンポーネントバス](componentBus3.md)
- 2x 拡張カード (ティア 2)
- 1x 拡張カード (ティア 3)
- 1x [EEPROM](eeprom.md)

ティア 3 サーバーは、以下のコンポーネントを搭載可能です：
- 1x ティア 3 [CPU](cpu3.md)
- 4x ティア 3 [RAM](ram5.md)
- 4x ティア 3 [HDD](hdd3.md)
- 3x ティア 3 [コンポーネントバス](componentBus3.md)
- 2x 拡張カード (ティア 2)
- 2x 拡張カード (ティア 3)
- 1x [EEPROM](eeprom.md)

ティア 4 (クリエイティブ) サーバーは、以下のコンポーネントを搭載可能です：
- 1x ティア 3 [CPU](cpu3.md)
- 4x ティア 3 [RAM](ram5.md)
- 4x ティア 3 [HDD](hdd3.md)
- 3x ティア 3 [コンポーネントバス](componentBus3.md)
- 4x 拡張カード (ティア 3)
- 1x [EEPROM](eeprom.md)
