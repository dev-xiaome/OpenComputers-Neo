# ケーブル

![スパゲッティ。](oredict:opencomputers:cable)

ケーブルは、離れた場所にある[コンピューター](../general/computer.md)やマシンを接続するための手段です。すべてのコンポーネントが直接または間接的に接触しているコンパクトな構成（ほとんどのブロックはケーブルと同様に機能します）であれば、通常ケーブルは不要です。

ケーブルは任意の染料で着色できます。着色されたケーブルは、同じ色のケーブルおよびデフォルトの色である薄灰色のケーブルにのみ接続されます。これは、カバーを使用せずに複数のサブネットワーク用のケーブルを並行して配線するのに便利です。

必要に応じて、Forge MultiPart カバーまたは Immibis Microblocks カバーを使用してケーブルを覆うことができます。[3Dプリント](print.md)は Forge MultiPart 互換であるため、必要に応じてカスタムカバーをプリントすることも可能です。
