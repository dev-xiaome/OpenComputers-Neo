# 解析機

![親父ギャグは我慢……。](oredict:opencomputers:analyzer)

解析機は、世界に設置されている OpenComputers 関連のブロックから情報を読み取るための便利なツールです。ブロックを（スニーク）アクチュベートするだけで、情報がチャットボックスに表示されます。情報の範囲は、コンポーネントのアドレスといった基本的なものから、ブロックが属するサブネットワークの電力レベル、[コンピューター](../general/computer.md)がクラッシュした原因となったエラー情報まで多岐にわたります。

もう1つの便利な機能として、ブロックまたはコンポーネントを Ctrl-右クリックすると、そのコンポーネントのアドレスがクリップボードにコピーされます。この情報は、必要に応じて[コンピューター](../general/computer.md)のターミナルに貼り付けることができます。
