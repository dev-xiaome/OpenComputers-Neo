# グラフィックスカード

![綺麗な画像。](oredict:opencomputers:graphicsCard1)

グラフィックスカードはほとんどの[コンピューター](../general/computer.md)にとって不可欠なパーツであり、接続された[スクリーン](../block/screen1.md)にテキストを表示できるようにします。グラフィックスカードにはいくつかのティアがあり、[スクリーン](../block/screen1.md)と同様に、対応する解像度や色深度が異なります。

もう1つの重要な違いは、1ティックあたりに実行できる操作の数です。グラフィックスカードのツールチップに記載されている数値は、ティア 2 の [CPU](cpu1.md) を搭載した[コンピューター](../general/computer.md)での代表値です。ティア 1 の CPU ではわずかに遅くなり、ティア 3 の CPU ではわずかに速くなります。記載されている数値は、GPU が提供する各操作（`copy`、`fill`、`set`、`setBackground`、`setForeground`）に対応しています。
