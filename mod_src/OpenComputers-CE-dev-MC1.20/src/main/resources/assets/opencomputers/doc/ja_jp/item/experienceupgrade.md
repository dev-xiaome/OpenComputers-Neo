# 経験値アップグレード

![意味がわからないけど、かっこいい。](oredict:opencomputers:experienceUpgrade)

経験値アップグレードは非常に特殊なアップグレードで、[ロボット](../block/robot.md)や[ドローン](drone.md)が鉱石の採掘やエンティティの殺害などの様々なアクションを通じて経験値を収集できるようになります。1つのアップグレードで最大30レベルまで蓄積でき、レベルごとに採掘速度の向上やエネルギーバッファ容量の増加などのパッシブボーナスが付与されます。

レベル 10 以上の[ロボット](../block/robot.md)は金色の色合いに、レベル 20 以上の[ロボット](../block/robot.md)はダイヤモンド色の色合いになります。

実際の経験値はアップグレード内部に保存されるため、アップグレードを別のデバイスに移し替えれば、経験値も一緒に引き継がれます。
