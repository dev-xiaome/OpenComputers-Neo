# タブレット (Tablet)

![触れるものなら触ってみろ。](item:opencomputers:tablet)

タブレットは、[タブレットケース](tabletcase1.md)を[アセンブラ](../block/assembler.md)に入れ、必要に応じて構成して組み立てることで作成されます。タブレットは持ち運び可能なコンピューターとして機能しますが、世界と直接やり取りすることはできません。例えば、基本的な[レッドストーンカード](redstonecard1.md)は動作しません。ただし、[看板 I/O](signupgrade.md) アップグレードや[ピストン](pistonupgrade.md)アップグレードなど、いくつかのアップグレードは動作します。

ティア 2 のタブレットでは、1つのコンテナアップグレードをインストールすることも可能です。コンテナによって提供されるスロットには、タブレットを手にした状態でシフト右クリックしてタブレットの代替 GUI を開くことでアクセスできます。この操作を行うと、タブレットは強制的にシャットダウンされます。

コンピューターとは異なり、タブレットの状態は、プレイヤーがゲームを終了して再接続した際には保持されません。また、ディメンションを越えて（プレイヤーがネザーに行って戻ってくるなど）も保持されません。

タブレットは[充電器](../block/charger.md)に入れてエネルギーを補充したり、充電器に接続された[コンピューター](../general/computer.md)からタブレット内の最初の[ハードドライブ](hdd1.md)にアクセスしたりすることができます。この状態では、充電器は[ディスクドライブ](../block/diskDrive.md)のように振る舞い、タブレットは[フロッピーディスク](floppy.md)のような役割を果たします。これは、タブレット内蔵のハードドライブに OS をインストールし忘れた場合や、タブレットの OS を壊してしまった場合に非常に便利です。

タブレットのもう1つの高度な機能は、世界の特定のブロックに関する情報を含む信号を生成する能力です。世界のブロックに対して約1秒間使用（右ボタンを押し続ける）してください。短いビープ音が鳴り、信号が生成されたことを知らせます。これは、情報を信号に付加するアップグレードがタブレットにインストールされている場合にのみ機能します。例えば、[ジオライザー](../block/geolyzer.md)はブロック自体の情報（硬さなど）を追加し、[ナビゲーションアップグレード](navigationupgrade.md)はタブレットを持っているプレイヤーに対するブロックの相対座標を追加します。分析対象のブロックは、タブレットを手に持っている間、緑色のオーバーレイで強調表示されます。
