# クラフトアップグレード

![器用。](oredict:opencomputers:craftingUpgrade)

クラフトアップグレードにより、[ロボット](../block/robot.md)は[インベントリ](../item/inventoryUpgrade.md)内のアイテムを使用して定型および不定型レシピをクラフトできるようになります。クラフト時、[ロボット](../block/robot.md)の[インベントリ](../item/inventoryUpgrade.md)の左上 3x3 グリッドがクラフトグリッドとして使用されます。アイテムはレシピに従って配置する必要があります。結果のアイテムはロボットのインベントリに戻されます。アイテムを拾うときと同様に、結果は選択されたスロットに配置され、不可能な場合は次に利用可能な空きスロットに配置されます。インベントリに空きがない場合、結果は世界にドロップされます。
