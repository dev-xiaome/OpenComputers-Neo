# データベースアップグレード

![データベースの中で生きる。](oredict:opencomputers:databaseUpgrade1)

データベースアップグレードは、アイテムスタックの情報を保存するように構成でき、他のコンポーネントから利用できます。これは、コールバックによって返される通常のアイテム情報には含まれない NBT データのみで区別されるアイテムを扱う際に特に便利です。

データベースを構成するには、データベースを手に持って右クリックして GUI を開きます。構成したいアイテムスタックを上のインベントリに配置します。これにより「ゴーストスタック」が保存されます。つまり、「実体」としてのアイテムはデータベースには保存されません。

あるいは、[インベントリコントローラー](inventoryControllerUpgrade.md)や[ジオライザー](../block/geolyzer.md)が提供するコンポーネント API を使用して、自動的にデータベースを構成することも可能です。
