# EEPROM

![パーティーを始めよう。](oredict:opencomputers:eeprom)

EEPROM には、コンピューターの起動時に初期化を行うためのコードが含まれています。このデータはプレーンなバイト配列として保存されており、[CPU](cpu1.md) アーキテクチャによって意味が異なる場合があります。例えば、Lua の場合は init スクリプトを含むファイルシステムを探すための小さなスクリプトですが、他のアーキテクチャでは実際のマシンコードである場合があります。

EEPROM は、[ドローン](drone.md)や[マイクロコントローラー](../block/microcontroller.md)などの特定の目的のためにプログラムすることができます。
