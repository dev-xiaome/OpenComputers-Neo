# ナノマシン

![ナノマシンだ。](oredict:opencomputers:nanomachines)

これらの小さな友人たちはあなたの神経系とインターフェースし、あなたをより強く、より良く、より速く、より逞しく、あるいはあなたを死なせます。時にはその両方が同時に起こります！ 簡単に言うと、ナノマシンは宿主であるプレイヤーにバフ（およびデバフ）を適用するためのエネルギー駆動型システムを提供します。ナノマシンを「インストール」するには、食べてください！

注入されると、HUD にナノマシンの残りエネルギーを示す新しいパワーインジケーターが表示されます。[充電器](../block/charger.md)の近くに立つことで充電できます。ナノマシンを活用すればするほど、多くのエネルギーを消費します。

ナノマシンは、誘発可能な一定数の「入力」を提供し、プレイヤーの近くでパーティクルを発生させるような視覚効果から、特定のポーション効果、そしてさらに稀で特別な動作まで、プレイヤーに多くの異なる効果をもたらします。

どの入力がどの効果を誘発するかは、ナノマシンの現在の構成に依存し、実際の「接続」は構成ごとにランダムになります。つまり、実際に各入力を有効にしてみて、何が起こるかを確認する必要があります。構成が気に入らない場合は、新しいバッチを注入（さらにもう一度食べる）することで、いつでもナノマシンを再構成できます。体内のナノマシンを完全に取り除きたい場合は、[酸](acid.md)を飲むことを検討してください。一度にあまりに多くの入力を有効にすると、深刻な悪影響を及ぼすので注意してください！

デフォルトでは、ナノマシンはスタンバイ状態です。無線メッセージを使用して制御する必要があるため、[無線ネットワークカード](wlanCard1.md)を搭載した[タブレット](tablet.md)を持ち歩くことを強くお勧めします。ナノマシンは、2メートル以内にいるデバイスからの無線信号にのみ反応しますが、あらゆるポートの、あらゆるデバイスからのメッセージに反応します。

ナノマシンはシンプルな独自プロトコルに反応します。各パケットは複数のパーツで構成されている必要があり、最初のパーツは「ヘッダー」であり文字列 `nanomachines` でなければなりません。2番目のパーツはコマンド名である必要があります。それ以降はコマンドのパラメータです。利用可能なコマンドは、`コマンド名(引数1, ...)` の形式で以下の通りです：

- `setResponsePort(port:number)` - レスポンスがあるコマンドに対して、ナノマシンがレスポンスメッセージを送信すべきポートを設定します。
- `getPowerState()` - ナノマシンの現在および最大蓄電量を要求します。
- `getHealth()` - プレイヤーの体力状態を要求します。
- `getHunger()` - プレイヤーの空腹状態を要求します。
- `getAge()` - プレイヤーの生存秒数を要求します。
- `getName()` - プレイヤーの表示名を要求します。
- `getExperience()` - プレイヤーの経験値レベルを要求します。
- `getTotalInputCount()` - 利用可能な全入力数を要求します。
- `getSafeActiveInputs()` - *安全* なアクティブ入力数を要求します。
- `getMaxActiveInputs()` - *最大* アクティブ入力数を要求します。
- `getInput(index:number)` - 指定されたインデックスの入力の現在の状態を要求します。
- `setInput(index:number, value:boolean)` - 指定されたインデックスの入力の状態を指定された値に設定します。
- `getActiveEffects()` - アクティブな効果のリストを要求します。一部の効果はこのリストに表示されない場合があります。
- `saveConfiguration()` - プレイヤーのインベントリに新しいナノマシンが必要で、それに現在の構成を保存します。

例（OpenOS の場合）：
- `component.modem.broadcast(1, "nanomachines", "setInput", 1, true)` - 最初の入力を有効にします。
- `component.modem.broadcast(1, "nanomachines", "getHealth")` - プレイヤーの体力情報を取得します。
