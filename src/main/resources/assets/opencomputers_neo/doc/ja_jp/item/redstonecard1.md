# レッドストーンカード

![赤が見える。](oredict:opencomputers:redstoneCard1)

レッドストーンカードにより、[コンピューター](../general/computer.md)は隣接するブロックのレッドストーン信号（アナログ）を読み取ったり出力したりできるようになります。入力された信号の強さが変化すると、[コンピューター](../general/computer.md)に信号が送られます。

RedLogic、Project Red、MineFactory Reloaded といった、統合された（バンドルされた）レッドストーン機能を提供する MOD や、WR-CBE、Slimevoid's Wireless mod といった無線レッドストーン機能を提供する MOD が導入されている場合、それらのシステムとやり取りできるティア 2 のカードが利用可能になります。

各種メソッドで指定する面は、[コンピューターケース](../block/case1.md) / [ロボット](../block/robot.md) / [ラック](../block/rack.md)の向きに対する相対的なものです。つまり、コンピューターの正面から見た場合、`sides.right` はあなたの左側になります（逆も同様です）。
