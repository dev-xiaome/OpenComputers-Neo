# マニュアル (取扱説明書)

![良い読み物です。](oredict:opencomputers:manual)

今あなたが読んでいるこれです！ マニュアルには OpenComputers (そしておそらくそれ以上) に関する膨大な情報が含まれています。MOD 内のアイテムやブロックに関する情報が必要な場合は、ここを探すだけで十分です。スクロールして使い方を確認してください（マウスホイールまたは右側のスクロールバー）。

![あなたの新しい親友。](opencomputers:doc/img/manual.png)

マニュアルの操作は Wiki の閲覧に似ています。リンク (1) をクリックして参照先のページに移動できます。右クリックまたはジャンプキーを押すと1ページ戻ります。エスケープキーまたはインベントリキーを押すとマニュアルを閉じます。左側にはいくつかのタブ (2) があり、ブロックやアイテムのインデックスなどの特定のページに素早く移動できます。右側にはスクロールバー (3) があります。手動でドラッグするか、マウスホイールを使用してページ内をスクロールできます。

マニュアルを再度開いたとき、最後に開いていたページが記憶されています。スニーク状態で使用することで、メインの目次ページからやり直すことができます。また、マニュアルを手にした状態で世界に設置されているブロックをシフト右クリックすることで、そのブロックに関するページを直接開くことも可能です。

マニュアルで解決しない質問がある場合は、[Wiki](https://ocdoc.cil.li)、OpenComputers の [IRC チャンネル](http://webchat.esper.net/?channels=#oc)、 [フォーラム](https://oc.cil.li/)などの場所を探してみてください。

マニュアルに間違い（事実、文法、その他）を見つけた場合や、MOD のバグを発見した場合は、[Issue tracker](https://github.com/MightyPirates/OpenComputers/issues) を通じてお知らせください。コンテンツを追加してマニュアルに貢献したい場合は、IRC または Issue tracker でチケットを作成して連絡してください。
