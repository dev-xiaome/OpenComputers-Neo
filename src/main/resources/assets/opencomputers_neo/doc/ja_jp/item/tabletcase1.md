# タブレットケース

![曲がりません。](oredict:opencomputers:tabletCase1)

タブレットケースは、[アセンブラ](../block/assembler.md)で[タブレット](tablet.md)を構築するためのベースパーツです。[タブレット](tablet.md)は非常にコンパクトで持ち運び可能な[コンピューター](../general/computer.md)です。いくつかの選択されたアップグレードを搭載できますが、[コンピューターケース](../block/case1.md)のように（簡単な[ネットワークカード](lanCard.md)や[レッドストーンカード](redstonecard1.md)などを使用して）世界とやり取りすることはできません。

[タブレット](tablet.md)で使用できないアップグレードやカードは、[アセンブラ](../block/assembler.md)に入れることができません。 [アセンブラ](../block/assembler.md)に入れることができるアップグレードであれば、コンポーネント API を介して利用可能です。

また、動作を継続するにはプレイヤーのインベントリ内に留まっている必要があります。ドロップしたり他のインベントリに入れたりすると、短時間で電源が切れます。

ティア 1 タブレットケースには、以下のコンポーネントを搭載可能です：
- 1x [CPU (ティア 2)](cpu2.md)
- 2x [RAM (ティア 2)](ram3.md)
- 1x [HDD (ティア 2)](hdd2.md)
- 2x 拡張カード (ティア 2)
- 1x [EEPROM](eeprom.md)
- 1x アップグレード (ティア 1)
- 1x アップグレード (ティア 2)
- 1x アップグレード (ティア 3)

ティア 2 タブレットケースには、以下のコンポーネントを搭載可能です：
- 1x [CPU (ティア 3)](cpu3.md)
- 2x [RAM (ティア 2)](ram3.md)
- 1x [HDD (ティア 2)](hdd2.md)
- 1x 拡張カード (ティア 2)
- 1x 拡張カード (ティア 3)
- 1x [EEPROM](eeprom.md)
- 2x アップグレード (ティア 2)
- 1x アップグレード (ティア 3)
- 1x [アップグレードコンテナ](upgradecontainer2.md) または [カードコンテナ](cardcontainer2.md) (ティア 2)

ティア 4 (クリエイティブ) タブレットケースには、以下のコンポーネントを搭載可能です：
- 1x [CPU (ティア 3)](cpu3.md)
- 2x [RAM (ティア 3)](ram5.md)
- 1x [HDD (ティア 3)](hdd3.md)
- 3x 拡張カード (ティア 3)
- 1x [EEPROM](eeprom.md)
- 9x アップグレード (ティア 3)
- 1x [アップグレードコンテナ](upgradecontainer3.md) または [カードコンテナ](cardcontainer3.md) (ティア 3)
