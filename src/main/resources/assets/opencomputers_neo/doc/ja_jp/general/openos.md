# OpenOS

OpenOS は OpenComputers で利用可能な基本的なオペレーティングシステムです。[コンピューター](computer.md)を最初に起動するために必要で、空の[フロッピーディスク](../item/floppy.md)と OpenComputers [マニュアル](../item/manual.md)を作業台でクラフトすることで作成できます。

作成した[フロッピーディスク](../item/floppy.md)を、[正しく構成された](quickstart.md) [コンピューター](computer.md)システムに接続された[ディスクドライブ](../block/diskDrive.md)に入れると、[コンピューター](computer.md)が OpenOS を起動できるようになります。

起動後は、OpenOS を空の[ハードドライブ](../item/hdd1.md)にインストールすることをお勧めします。これによりフロッピーディスクが不要になり、読み書き可能なファイルシステムを利用できるようになります（OpenOS の[フロッピーディスク](../item/floppy.md)やその他の「戦利品」ディスクは読み取り専用です）。ティア3の[コンピューターケース](../block/case3.md)にはフロッピー用のスロットが内蔵されているため、[ディスクドライブ](../block/diskDrive.md)は不要です。

OpenOS は単に `install` と入力して実行し、画面の指示に従うだけでインストールできます。システムが再起動したら、[フロッピーディスク](../item/floppy.md)を取り外しても構いません。OpenOS は[ドローン](../item/drone.md)と[マイクロコントローラー](../block/microcontroller.md)を除くすべてのデバイスにインストールできます（これら2つはファイルシステムを内蔵していないため、機能を提供するには [EEPROM](../item/eeprom.md) を手動でプログラムする必要があります）。

OpenOS には多くの組み込み関数がありますが、最も便利なのは `lua` コマンドで、Lua インタープリターを開きます。これは、コマンドを .lua スクリプトとして書き込む前に、様々なコマンドを試したりコンポーネント API を実験したりするための良いテストスペースになります。インタープリターを開始したときに表示される情報に注意してください。入力したコマンドの結果を表示する方法や、終了する方法が記載されています。

プログラミングの詳細については、[Lua プログラミング](lua.md) のページを参照してください。Lua スクリプトを実行するには、単にファイル名を入力して Enter を押します（例：`script.lua` はターミナルで `script` コマンドを入力することで実行できます）。
