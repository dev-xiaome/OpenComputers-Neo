# キーボード

![QWERTY](oredict:opencomputers:keyboard)

キーボードは、設置されている[スクリーン](screen1.md)や、[ロボット](robot.md)や[タブレット](../item/tablet.md)などのデバイスに内蔵されているスクリーンにテキストを入力するために必要です。

設置されている[スクリーン](screen1.md)でキーボードを使用するには、スクリーンの隣にスクリーンを向くように配置するか、スクリーン自体（上面または側面）に直接配置する必要があります。キーボードを使用して[スクリーン](screen1.md)の GUI が開けば、キーボードがスクリーンに「接続」されていることがわかります。
