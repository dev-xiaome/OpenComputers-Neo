# ラック

![無料の住処。](oredict:opencomputers:rack)

ラックには、[サーバー](../item/server1.md)、[ターミナルサーバー](../item/terminalServer.md)、[マウント型ディスクドライブ](../item/diskDriveMountable.md)などのラックマウント用デバイスを最大4つまで収容できます。ラック内の各デバイスの接続性は、GUI を介して詳細に構成できます。特に、[サーバー](../item/server1.md)に[ネットワークカード](../item/lanCard.md)などの対応コンポーネントが含まれている場合、それらのコンポーネント専用のネットワーク接続を定義できます。これらの接続は純粋にネットワークメッセージを受け渡すために機能し、コンポーネントを直接操作することはできません。このようなネットワーク専用接続は、「メイン」の接続（コンポーネントアクセスも可能）よりも細い線で区別されます。内部接続は、マウントされたデバイス内のコンポーネントと、ラックの側面に接続されたバスの間で行う必要があります。複数のデバイスを互いに接続するには、それらを同じバスに接続してください。

ラックは、[中継機 (リレイ)](relay.md)と[パワーディストリビューター](powerDistributor.md)の両方の機能を併せ持っています。中継機として機能させるかどうかはラックの GUI で構成でき、有効な場合はサイドバスの間にコネクタ線が表示されます。
