# レッドストーンI/O

![こんにちは、レッド。](oredict:opencomputers:redstone)

レッドストーンI/Oブロックは、離れた場所からレッドストーン信号を読み取ったり放出したりするために使用できます。これはティア 1 と ティア 2 の[レッドストーンカード](../item/redstoneCard1.md)のハイブリッドのような動作をします。単純なアナログ信号だけでなくバンドル信号も読み書きできますが、無線レッドストーン信号の送受信はできません。

このブロックが提供するコンポーネントのメソッドに「面 (side)」を指定する場合、その方向は世界のグローバルな方角を指します。ブロックのテクスチャには、各面の数値に対応する微妙な凹みがあります。また、`sides.north` や `sides.east` などのグローバル値を使用することもできます。

[レッドストーンカード](../item/redstoneCard1.md)と同様に、このブロックはレッドストーン信号の状態が変化したとき（アナログ信号およびバンドル信号の両方）に、接続された[コンピューター](../general/computer.md)に信号を注入します。また、特定の入力強度を超えたときに接続された[コンピューター](../general/computer.md)をウェイクアップするように構成することもでき、[コンピューター](../general/computer.md)の自動起動が可能になります。
