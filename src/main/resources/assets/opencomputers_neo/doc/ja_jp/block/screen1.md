# スクリーン

![これが見えますか？](oredict:opencomputers:screen1)

スクリーンは[グラフィックスカード](../item/graphicsCard1.md)と組み合わせて使用され、[コンピューター](../general/computer.md)がテキストを表示できるようにします。スクリーンのティアによって、対応する解像度や色深度などの機能が異なります。低解像度の白黒ディスプレイから、最大256色を表示可能な高解像度ディスプレイまであります。

利用可能な解像度と色深度は、使用しているコンポーネントのうち最も低いティアのものに基づきます。[ティア 3 スクリーン](screen3.md)で[ティア 1 グラフィックスカード](../item/graphicsCard1.md)を使用する場合、ティア 1 の解像度と色深度しか利用できません。しかし、ティア 1 スクリーンでティア 3 [グラフィックスカード](../item/graphicsCard1.md)を使用する場合、解像度と色深度はティア 1 に制限されますが、[グラフィックスカード](../item/graphicsCard1.md)の操作速度はティア 1 カードを使用する場合よりも速くなります。

スクリーンは、同じ方向を向いている限り、隣行に並べてマルチブロックスクリーンを形成できます。上向きまたは下向きに配置する場合は、回転方向も同じにする必要があります。向きは、スクリーンを手に持っているときに表示される矢印のオーバーレイで確認できます。

スクリーンのサイズは利用可能な解像度には影響せず、ティアのみが影響します。隣接するスクリーンとの接続を制御するために、スクリーンを染色することもできます。染料を手に持ってスクリーンを右クリックするだけです。染料は消費されませんが、スクリーンを破壊したときに色は保持されません。色が異なるスクリーン同士は接続されません。また、ティアが異なるスクリーン同士も、色が同じであっても接続されません。

ティア 2 および ティア 3 のスクリーンはマウス入力にも対応しています。クリック操作はスクリーンの GUI 内で行うか（[キーボード](keyboard.md)が接続されている場合のみ開けます）、スニーク（しゃがみ）状態でスクリーンを使用することで行えます。スクリーンに[キーボード](keyboard.md)がない場合、スニークは不要です。なお、スニーク状態または通常状態でスクリーンをアクチュベートしたときに GUI を開くかどうかは、接続された[コンピューター](../general/computer.md)に公開されているコンポーネント API を使用して制御できます。ティア 3 スクリーンでは、コンポーネントで有効にすれば、より正確なヒット位置の検出が可能です。例えば、シングルキャラクター空間の上半分と下半分のどちらがクリックされたかを検出でき、これは特殊な Unicode 文字を使用して疑似的に高解像度化している場合に便利です。

スクリーンの解像度と色深度は以下の通りです：
- ティア 1: 50x16、1ビットカラー。
- ティア 2: 80x25、4ビットカラー。
- ティア 3: 160x50、8ビットカラー。
