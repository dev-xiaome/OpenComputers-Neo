# 中継機 (リレイ)

![架け橋。](oredict:opencomputers:relay)

中継機を使用すると、コンポーネントを他のネットワークの[コンピューター](../general/computer.md)にさらすことなく、異なるサブネットワーク間でネットワークメッセージを送受信できるようになります。コンポーネントをローカルに保つことは、[コンピューター](../general/computer.md)が誤った[スクリーン](screen1.md)を使用するのを防いだり、コンポーネントのオーバーフロー（[コンピューター](../general/computer.md)がクラッシュして起動しなくなる原因になります）を回避したりするために、通常良い考えです。

中継機に[無線ネットワークカード](../item/wlanCard1.md)を挿入すると、メッセージを無線で中継するようにアップグレードできます。無線メッセージは、無線ネットワークカードを持つ他の中継機や、無線ネットワークカードを搭載した[コンピューター](../general/computer.md)によって受信・中継されます。

あるいは、[リンクカード](../item/linkedCard.md)を使用して中継機をアップグレードすることもできます。この場合、リンクカードが提供するトンネルを通じてメッセージを転送します。通常のコストがかかるため、中継機に十分な電力が供給されていることを確認してください。

中継機は、最近転送したパケットを記憶 *しません*。そのため、ネットワーク内にループを作らないようにしてください。さもないと、同じパケットを複数回受信する可能性があります。中継機のバッファサイズには限りがあるため、メッセージを頻繁に送信しすぎるとパケットロスが発生します。中継機をアップグレードして、メッセージの中継速度や内部のメッセージキューサイズを増やすことができます。

パケットの再送信回数には制限があるため、中継機を無制限に連結することはできません。デフォルトでは、パケットは最大5回まで再送信されます。
