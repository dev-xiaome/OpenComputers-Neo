# File Cabinet

![Finally, somewhere to put all those TPS reports.](item:opencomputers:filecabinet)

The File Cabinet provides 30 storage slots intended for documents and office supplies.

It accepts [Printed Pages](../item/printedpage.md), [Folders](../item/folder.md), paper, books, writable books, and written books. Automation can access its inventory through the normal item-handler capability.
