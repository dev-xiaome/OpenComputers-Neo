# Printer Ink Cartridges

![Black Ink Cartridge](item:opencomputers:printer_ink_black)
![Color Ink Cartridge](item:opencomputers:printer_ink_color)

The [Document Printer](../block/documentprinter.md) uses separate black and color ink cartridges.

Black text consumes black ink. Colored lines and image/map printing consume color ink. A print job pauses rather than discarding work if the required cartridge runs out.

Both cartridge types can be crafted and refilled using their normal recipes.
